# Contributing

tpt-window accepts **issues only**. Pull requests are not accepted.

- Bug reports, feature requests and questions: open an issue at
  https://github.com/tpt-solutions/tpt-window/issues.
- Please include your platform, backend, and a minimal reproduction.
- Do not report security problems with exploit details in a public issue; say that
  you have a security concern and a maintainer will follow up.
